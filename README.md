# Зет в поисках себя

Поэтический квест-приключение в стиле ленинградского рока, реализованный как одностраничная HTML5/Canvas-игра на чистом JavaScript. Игрок следует за главным героем Зетом через семь локаций (сцены `l1`–`l7`), собирая предметы и решая головоломки, чтобы «найти себя».

## Особенности

- **Без зависимостей и сборки** — вся логика игры находится в одном файле `Zeth.html`.
- **Графика**: спрайты персонажа, фоны локаций, иконки предметов и логотип (PNG/JPG).
- **Звук и музыка**: фоновые треки, звуки окружения (улица, автобус, капли, часы) и камео-треки в финале.
- **Шрифт** Amatic SC (TTF) для рукописного стиля интерфейса.
- Русскоязычный интерфейс и озвучка событий текстом.

## Структура проекта

```
.
├── Zeth.html          # Игра: HTML + CSS + весь JavaScript
├── fonts/             # Шрифты (AmaticSC-Regular.ttf)
├── images/
│   ├── backs/         # Фоны локаций (back0.jpg … back5.jpg, svetofor.jpg)
│   ├── character/     # Спрайты героя (front, left1/2, right1/2)
│   ├── icons/         # Предметы инвентаря и курсор
│   └── logos/         # Логотип игры
├── music/             # Музыкальные треки (main_theme, theme2, tsoy, letov)
└── sounds/            # Звуковые эффекты (шаги, улица, автобус, капли, аплодисменты)
```

## Запуск

Так как игра использует относительные пути к ресурсам, её нужно открывать через локальный HTTP-сервер (просто двойной клик по HTML-файлу может работать с ограничениями из-за политики загрузки аудио/шрифтов).

Вариант 1 — Python:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/Zeth.html
```

Вариант 2 — Node.js:

```bash
npx --yes serve -l 8000 .
# затем открыть http://localhost:8000/Zeth.html
```

## Управление

- **Мышь** — перемещение по игровому полю (кастомный курсор), взаимодействие с предметами и hotspot'ами.
- **Клик по предмету в мире** — добавить в инвентарь.
- **Инвентарь внизу экрана** — использовать/комбинировать предметы.
- Первая пользовательская реакция (клик или клавиша) запускает музыку — это требование браузеров к автопроигрыванию звука.

## Сцены

| Сцена | Описание |
|-------|----------|
| `splash` | Заставка с логотипом |
| `menu`   | Главное меню |
| `l1`–`l7` | Сюжетные локации: двор, кухня, подъезд, улица, переход, финал |
| `l7end`  | Финальная сцена |

## Лицензия
