# Зет в поисках себя

Поэтический квест-приключение в стиле ленинградского рока, реализованный как одностраничная HTML5/Canvas-игра на чистом JavaScript. Игрок следует за главным героем Зетом через локации собирая предметы и решая головоломки, чтобы «найти себя».

## Особенности

- **Без зависимостей и сборки** — вся логика игры находится в одном файле `Zeth.html`.
- **Графика**: спрайты персонажа, фоны локаций, иконки предметов и логотип (PNG/JPG).
- **Звук и музыка**: фоновые треки, звуки окружения (улица, автобус, капли, часы) и камео-треки.
- **Шрифт** Amatic SC (TTF) для рукописного стиля интерфейса.
- Русскоязычный интерфейс и озвучка событий текстом.

## Структура проекта

```
.
├── Zeth.html          # Игра: HTML + CSS + весь JavaScript
├── fonts/             # Шрифты (AmaticSC-Regular.ttf)
├── images/
│   ├── backs/         # Фоны локаций (back0.jpg … back5.jpg, svetofor.jpg)
│   ├── character/     # Спрайты героя и существ (front, left1/2, right1/2)
│   ├── icons/         # Предметы инвентаря и курсор
│   └── logos/         # Логотип игры
├── music/             # Музыкальные треки (main_theme, theme2, tsoy, letov)
└── sounds/            # Звуковые эффекты (шаги, улица, автобус, капли, аплодисменты)
```

## Запуск

Для запуска игры необходимо скачать в разделе Code - Download Zip
Распаковать архив, а потом запустить Zeth.html

## Управление

- **Мышь** — перемещение по игровому полю (кастомный курсор), взаимодействие с предметами и hotspot'ами.
- **Клик по предмету в мире** — добавить в инвентарь.
- **Инвентарь внизу экрана** — использовать/комбинировать предметы.
- Первая пользовательская реакция (клик или клавиша) запускает музыку — это требование браузеров к автопроигрыванию звука.

## Лицензия

Ресурсы (изображения, музыка, шрифты) принадлежат их авторам; код проекта распространяется свободно для некоммерческого использования.
