# Зет в поисках себя — карта проекта (для AI-ассистентов)

Одностраничная point-and-click игра. Весь код — в `Zeth.html` (~1340 строк: HTML + CSS + JS).
Ресурсы подгружаются из папок рядом с файлом. Игровой движок — Canvas 2D, без фреймворков.

## Как добавить новый уровень (чек-лист на примере l8)

1. **Фон.** Положите картинку в `images/back/`, загрузите через `IMG.backN` и добавьте маппинг
   в объект фонов: `l8: IMG.back6`.
2. **Зоны взаимодействия.** Создайте массив `H8` по образцу `H1…H7`: каждая зона = координаты
   (x, y, w, h) + текст `say` (реплика NPC/подсказка) + при необходимости обработчик клика.
   Формат зон смотрите внутри `Zeth.html` — не выдумывайте структуру, копируйте существующую.
3. **Регистр кликов.** Добавьте `{l8: H8}` в объект, связывающий сцену с её зонами.
4. **Вход в уровень.** Функция `startL8()`: задать `S.scene='l8'`, выбрать музыку/звук,
   поставить стартовую позицию персонажа.
5. **Логика и отрисовка.** В обработчиках взаимодействий и в функции `draw()` добавьте ветки
   `if(S.scene=='l8')`.
6. **Переход.** В финале предыдущего уровня замените окончание на `fadeTo(startL8)`
   (`fadeTo` — стандартный переход с затемнением).

Пояснения NPC хранятся в поле `say` зон; для диалогов используйте хелпер `npc()`
и словари персонажей внутри файла.

## Глобальное состояние

Единый объект `S` (сцена, инвентарь, флаги, позиция героя). Все изменения состояния —
только через функции-обработчики внутри файла. Перед правкой конкретного места —
просите ассистента открыть соответствующий участок кода, а не менять вслепую.

## Правила правок (важно!)

- Сохранять все сцены, координаты, анимации и игровые механики.
- НЕ менять игровые тексты и авторскую стилистику (это художественное произведение автора).
- НЕ переписывать Canvas-движок на другой фреймворк.
- После каждого изменения — проверять работоспособность игры.
- Крупные изменения (новый уровень, рефакторинг) — в отдельной Git-ветке,
  не сливать в master самостоятельно.

## Развертывание

Сайт живёт на https://bassur.netlify.app/zeth (Netlify). Публикация — копированием файлов
(`Zeth.html` + папки images/sounds/music/fonts). Долгая загрузка обычно из-за веса
картинок/аудио — перед загрузкой новых ресурсов их стоит сжать
(фото → JPG ~200–300 КБ, музыка → MP3 96–128 kbps).

## Известные особенности

- Гитарная мини-игра: активная зона специально сделана шире аккорда (учитывает пересечение,
  а не только центр) — не «чинить» обратно.
- Кондуктор в трамвае сразу называет цену билета (25 руб.) — это исправление отзыва, не убирать.
